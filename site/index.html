WORLD 3

Stage Map

Every meaningful change plays the same four stages. The free, deterministic checks always run before anything that costs money.

1

STAGE 1-1

Plan Hearing

The agent writes a plan listing its evidence and the files it may touch. The Prosecutor and Defender each object, the agent responds, and the Judge rules.

🔒 No code until approved

2

STAGE 1-2

Build

Only the approved plan gets built. Rule changes bump the rulebook version, and every test names the rule it enforces.

📜 Scoped by contract

3

STAGE 1-3 · BOSS

Gate + Blind Trial

A $0 diff gate fails any surprise change. Then an independent Party B competes with the agent's work, and the Bailiff and Judge settle each disagreement.

🪙 $0.00 gate · verified quotes only

4

STAGE 1-4

Closing

Every remaining loss is grouped and labelled: fix the rule, fix the code, accept the limit, or escalate to you.

🏁 continue or consensus

TIP: A continue verdict sends you back to Stage 1-1 with a new plan. The run ends on consensus, and then you decide whether to commit.

BAILIFF

FAQ

Do I need an API key?

Not to try it. Every command defaults to --provider mock, which runs offline at $0.00 (CI uses it too). For real reviews, install an extra (.[anthropic], .[openai], .[bedrock]) and pass --provider.

Isn't this too much process for small changes?

For a typo fix, yes, so skip it. The $0 replay gate is cheap enough to run on every change. Save full hearings and trials for work with real blast radius, or work that has to stay consistent with earlier decisions.

How is this different from a "senior engineer" persona prompt?

A persona changes the agent's style. Courtroom adds structure: two advocates arguing opposite sides, evidence verified in Python, a deterministic file-scope gate, and append-only case law that persists across sessions. Keep your style preferences in conventions.md and use both.

Can I write plans in Markdown?

Yes. .md and .yaml plans and rebuttals are compiled to validated JSON automatically.

What does it cost with real models?

You set the ceiling with --budget-usd. Calls are cached by content hash, logged to a ledger, and blocked before they would exceed the cap. Party B and unchanged trials are reused across rounds. The sample round costs about $0.06.
